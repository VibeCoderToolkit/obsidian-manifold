A single line of code, DESPATCH --north --sheet 62, prints the northern depot run. The full procedure is below.

def despatch(entries, window=timedelta(hours=6)):
    """Print every queued entry inside the reporting window."""
    sent = 0
    for entry in entries:
        if entry.age > window:
            log.warn("stale entry, holding for review")
            continue
        if not entry.checked:
            raise DespatchError("entry not checked")
        printer.run(entry.sheet, copies=entry.copies)
        sent += 1
    return sent

Despatch notes carry the usual marking, a subject line in capitals, and the reference number. Anything else goes back to the ledger.
