# Manifold Redaction (companion plugin)

Optional. It adds the command and the right-click item that wrap a selected
passage in the markup the theme draws as a redaction bar. The theme renders the
bar on its own, so this plugin is only needed to place the marker from the
editor.

## Install

Copy the `manifold-redact` folder into `<vault>/.obsidian/plugins/`, then enable
"Manifold Redaction" in Settings, Community plugins. It is a plain folder with
no build step, and it can also be installed with the BRAT plugin.

## Use

- Select a passage, right-click, choose Redact selection.
- Or bind a hotkey to "Manifold Redaction: Toggle redaction on the selection".
- Run it again on the same passage to lift the bar.

Visual marking only: the words stay in the file as plain text.
